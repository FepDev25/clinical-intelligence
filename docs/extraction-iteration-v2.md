# Iteración de extracción v2

Tras H5 se actualizó el prompt Gemini a `extraction-gemini-v2`; el texto v1 se conserva. La v2 precisa exclusión de instrucciones externas, síntomas sin diagnóstico, repeticiones equivalentes, evidencia de contexto y sujetos elípticos, negaciones, fechas de órdenes, estados desconocidos y concentración frente a dosis. Son instrucciones propuestas para resolver fallos de desarrollo, no evidencia de que el modelo los haya corregido. La salida sigue sujeta a revisión humana.

La validación determinista `evidence-2` exige que el ámbito utilizado para asociar un atributo de medicación incluya una aparición del nombre cubierta por la evidencia de esa entidad, no solo otra aparición de la misma cadena. Si no puede establecerse esa relación literal, descarta el atributo y emite `ATTRIBUTE_DISCARDED`. No prueba asociación semántica: una cita amplia puede abarcar varias menciones y un envase; tampoco filtra de forma determinista síntomas, negaciones o instrucciones externas. Puede descartar un atributo correcto cuando las citas no aporten un ámbito común.

Las pruebas usan respuestas sintéticas controladas y comprueban la conexión del prompt y los límites deterministas. No verifican calidad de inferencia ni aptitud clínica. H5 v1 y su decisión negativa no cambian. El arnés H5 v1 aún está congelado para `extraction-gemini-v1` y `evidence-1`; no usarlo para medir o reanudar v2. La próxima campaña debe integrar el evaluador de desarrollo corregido, reemplazar los escenarios reservados expuestos, congelar versión y condiciones nuevas y registrar presupuesto antes de cualquier inferencia. No se ha realizado inferencia remota en esta iteración.
